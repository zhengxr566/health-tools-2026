健康计算工具：体重、热量、营养、运动与睡眠

CalmyHealth 提供 BMI、基础代谢（BMR）、每日总消耗（TDEE）、体脂率、蛋白质与营养摄入、步数换算、睡眠周期等常用健康计算工具， 以及配套的健康指南文章。每个工具都会说明用了哪个公式、结果怎么看、有哪些局限，并列出参考来源。

简体中文版采用中国成人体重判定标准和《中国居民膳食营养素参考摄入量（2023 版）》；繁体中文版采用台湾国民健康署标准； 日语版采用日本肥满学会和《日本人の食事摂取基準》。计算结果仅供日常参考，不能代替医生的诊断。

按目标开始

想减脂

先确认体重是否真的需要减，再算出每天的消耗和合适的热量缺口，最后保证蛋白质足够，减脂时少掉肌肉。

BMI → TDEE → 热量缺口 → 蛋白质
想增肌

用体脂率和 FFMI 了解目前的肌肉量，在 TDEE 基础上略增热量，并把蛋白质分配到每一餐。

体脂率 → FFMI → 三大营养素 → 餐次分配
想吃得更均衡

把一天吃的东西记下来，看看钙、纤维、钾等营养素够不够，再用食物营养图谱找能补上的食物。

一日饮食营养分析 → 食物营养图谱 → 盐摄入
想多动、睡得好

把步数换算成距离和热量，设定适合自己的步数目标；按睡眠周期安排入睡和起床时间。

步数换算 → 步数目标 → 睡眠周期 → 睡眠债
