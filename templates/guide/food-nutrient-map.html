先说结论

  • 同一群的食物营养高度重合：白米饭、面条、米粉、馒头几乎可以互相替换；鸡胸肉和金枪鱼、罗非鱼、猪里脊也很接近。在同一群里换来换去，营养不会多出什么。
  • 不同群的食物作用不一样：肉鱼擅长蛋白质和锌，奶和豆制品擅长钙，深绿叶菜擅长铁、钙、维生素 A，橙黄色蔬菜擅长维生素 A，水果擅长维生素 C 和钾。
  • 营养素常常“结伴”：钾、镁、铁和膳食纤维常一起出现在蔬菜和豆类里；蛋白质和锌常一起出现在肉里。所以缺其中一样时，往往其他几样也不够。
  • 怎么用：每餐从不同的营养群里各挑一样，比在同一群里挑“最好的那个”更重要。

“吃得杂”是营养建议里最常听到的一句话，但到底怎样才算杂？如果一天吃了米饭、面条和馒头，看起来换了三种主食，其实营养几乎一样。 本文把本站 一日饮食营养分析 用到的 109 种常见食物，按营养素组成做了聚类分析，画成一张“食物营养图谱”， 让你一眼看出哪些食物营养重合、哪些食物能互相补位。

这张图谱是怎么做的

  1. 数据：每 100 g 食物的营养素数值来自卫生福利部食品药物管理署“食品营养成分资料库”和美国农业部 FoodData Central；调味料（盐、酱油、蚝油、番茄酱）和几乎没有热量的美式咖啡不纳入。
  2. 比的是“营养素密度”：按每 100 kcal 能提供多少蛋白质、膳食纤维、钾、钙、铁、镁、锌、维生素 A、维生素 C 和钠来比较，再加上脂肪和碳水的供能比例。这样可以排除“吃多少”的影响，只看食物本身的营养组成。
  3. 分群：各项数值取对数、标准化后，用 Ward 法做层次聚类，分成 11 个营养群；二维图谱用主成分分析（PCA）把 12 个维度压缩到平面上。

按热量来比会让低热量的蔬菜显得特别“营养”，所以文末另外附上按“一份”计算的排行，两种角度一起看更完整。

读图方法很简单：两个点越近，营养组成越像。大致可以分成四个方向：

  • 右侧：蔬菜、海藻。每 100 kcal 的维生素、矿物质最多，是“微量营养素密度”最高的一区。
  • 左侧：白米饭、面条、油、可乐、啤酒、薯片等。主要提供能量，维生素和矿物质相对少。
  • 上方：水果、主食、甜饮料，能量主要来自碳水化合物。
  • 下方：肉、鱼、蛋、奶、豆制品和坚果，能量主要来自蛋白质和脂肪。

营养重合的食物：换着吃差别不大

同一群里的食物，营养组成非常接近。下面是图谱中距离最近的几组：

食物营养最接近的食物说明
白米饭米粉、面条、馒头都是精制谷物，主要提供碳水；换成彼此并不会多出维生素或矿物质
鸡胸肉金枪鱼罐头、罗非鱼、鸡腿肉、猪里脊高蛋白、低脂肪；需要换口味时可以放心互换
西兰花卷心菜、青椒、四季豆、生菜维生素 C、钾、纤维；但维生素 A 都不多
香蕉土豆、梨、葡萄、苹果碳水 + 钾；香蕉和土豆在营养上比想象中更接近
全脂牛奶酸奶、低脂牛奶、拿铁、鲜奶茶钙和蛋白质；奶茶和拿铁的营养主要来自其中的牛奶
老豆腐嫩豆腐、无糖豆浆、豆腐干、黑芝麻粉钙、镁、铁和蛋白质

所以，如果某种营养素不够，在同一群里换食物帮助有限，应该从别的群里找。

作用不同的食物：搭配才能互补

{{ ui.figure("nutrient-correlation") }}

这张相关矩阵显示了哪些营养素常常“结伴”出现：钾和镁（相关系数 0.80）、铁和镁（0.83）、膳食纤维和钾（0.79）都高度相关，它们主要一起来自蔬菜、豆类和全谷物； 蛋白质和锌（0.68）则主要一起来自肉类。这也解释了为什么少吃蔬菜的人，往往钾、镁、纤维会同时不够。

常见的互补搭配：

  • 白米饭 + 豆花 / 牛奶 + 红薯 + 菠菜：米饭缺钾、镁、钙，这三样各补一块。
  • 鸡胸肉 + 番石榴 / 西兰花 + 地瓜叶：肉类缺膳食纤维、维生素 C 和钙。
  • 牛奶 + 西兰花 + 红薯 + 地瓜叶：奶类缺膳食纤维、铁和维生素 C。
  • 菠菜等植物性铁 + 维生素 C 丰富的水果或青椒：维生素 C 有助于植物性（非血红素）铁的吸收。

用这张图搭配一日三餐

  1. 每餐至少 3 个群：一个主食群（尽量选全谷、薯类）、一个蛋白质群（肉鱼、蛋奶或豆制品）、一个蔬菜群。
  2. 蔬菜一天跨 2–3 个群：浅色蔬菜、橙黄色蔬菜、深绿叶菜各有所长，只吃生菜黄瓜就会缺维生素 A 和铁。
  3. 每天 1–2 份奶类或豆制品：这是钙最主要的来源。
  4. 水果当点心：番石榴、猕猴桃、橙子一份就能提供大部分维生素 C。
  5. 精制主食和甜饮料控制份量：它们主要提供能量，吃多了容易挤掉其他群的位置。

局限与注意事项

  • 聚类结果取决于选了哪些营养素：本图谱没有包含维生素 D、B 族维生素、碘、ω-3 脂肪酸、糖、饱和脂肪等，例如鲭鱼和三文鱼的 ω-3 优势在这里看不出来。
  • 营养素数值是数据库的代表值，品种、产地、烹调方式都会造成差异。
  • “营养相似”不等于“健康程度相同”：例如白米饭和可乐在微量营养素上同样少，但可乐含大量添加糖。
  • 本文用于饮食教育，不能代替医生或营养师的个别建议；有慢性肾病、痛风、糖尿病等疾病时，请按医嘱调整饮食。
